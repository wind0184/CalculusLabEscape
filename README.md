# Calculus Lab Escape

Calculus Lab Escape is a cyberpunk-themed 3D educational puzzle game for pre-university students. Players restore a corrupted mathematics laboratory by solving interactive challenges involving limits, differentiation, and integration.

## Current milestone

**Version 1.0 — Limits Chamber vertical slice**

The first playable increment will include:

1. First-person movement and object interaction.
2. A small Limits Chamber environment.
3. A holographic puzzle panel.
4. A draggable approaching-value visualization.
5. Progressive hints and immediate feedback.
6. A security door that opens after a correct solution.
7. A level summary with time, attempts, accuracy, and hints used.

## Development environment

- Unity 6000.3.10f1
- Windows PC
- Single-player prototype

## Repository rules

Only `Assets`, `Packages`, `ProjectSettings`, and project documentation should be committed. Unity-generated folders such as `Library`, `Temp`, `Logs`, and `UserSettings` are excluded.
